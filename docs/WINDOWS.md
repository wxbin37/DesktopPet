# Windows 版使用说明

## 直接运行

- 男生版：双击 `DesktopPet.exe`
- 女生版：双击 `DesktopPetGirl.exe`
- 不需要安装 Python，也不需要打开命令行
- 桌宠启动后会常驻桌面最上层，右下角系统托盘中也有桌宠图标

## 基本操作

- 左键按住桌宠可拖动，松开后会在新位置附近活动
- 右键桌宠或右下角托盘图标可以切换动作、测试键盘动画或退出
- 敲击真实键盘时，小人会切换到趴桌敲键盘状态，并同步高亮键位
- 程序只监听按键节奏，不会代替你输入、点击页面或保存输入内容

## Windows 安全提示

当前版本没有购买商业代码签名证书。Windows 第一次打开时可能显示“Windows 已保护你的电脑”。如果文件来自本项目官方发布页，请点“更多信息”，再点“仍要运行”。

部分安全软件会对“全局键盘监听”比较敏感，因为桌宠需要知道你何时敲键盘才能播放动画。程序只在本机内存中响应按下/松开事件，不记录或上传按键内容。

## 退出

在桌宠或右下角托盘图标上点右键，选择“退出”。直接关闭桌宠窗口只会隐藏到托盘。
